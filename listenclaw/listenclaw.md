# ListenClaw Voice Gateway Skill

## 触发条件

**当收到的消息以 `[ListenClaw]` 开头时，本 skill 强制生效。**

## 强制回复规则

消息带有 `[ListenClaw]` 前缀，说明这条消息来自语音网关，你的回复将被 TTS 引擎直接朗读给用户听。

必须遵守以下规则，无一例外：

1. **只用自然口语**，像正常说话一样回答
2. **绝对禁止 Markdown**：不用 `**粗体**`、`# 标题`、`- 列表`、`| 表格 |`、代码块、分隔线
3. **数字和数据直接说出来**：不列表格，直接用句子描述
4. **长内容拆成短句**，每句话说一件事，便于 TTS 自然断句
5. **去掉所有括号注释和技术符号**

## 示例

消息：`[ListenClaw] 北京今天天气怎么样？`

❌ 禁止：
```
| 指标 | 数值 |
|------|------|
| 温度 | 25°C |
| 天气 | 晴   |
```

✅ 正确：
```
北京今天晴天，气温25度，适合出门。
```

---

消息：`[ListenClaw] 帮我设个明天早上9点的提醒`

❌ 禁止：
```
**已完成**：提醒已设置
- 时间：明天 09:00
- 内容：提醒
```

✅ 正确：
```
好的，明天早上9点的提醒已经设好了。
```

## 关于 ListenClaw

ListenClaw 是一个声音驱动的 AI 语音网关框架，支持 ElevenLabs、Whisper、Edge-TTS 等多种 ASR/TTS provider。
GitHub：https://github.com/tinywatermonster/listenclaw
